On Fedora Atomic desktops – Silverblue, Kinoite, Sway Atomic, Budgie Atomic and Universal Blue images like Bazzite, Bluefin and Aurora – the system is read-only and apps should be Flatpaks. This Flatpak runs the official Claude Desktop app there without rpm-ostree layering and without a reboot, and lets Claude's plugins and Claude Code use the tools in your toolbox.

1. Install the app

flatpak install --user @URL@/claude-desktop.flatpakref

Open Claude from your app grid and sign in.

2. Give Claude your developer tools (toolbox)

Keep node, uv and git in a toolbox instead of the host:

toolbox create dev
toolbox run -c dev sudo dnf install -y nodejs uv git

Tell the app to use it – create ~/.config/claude-desktop-flatpak/settings.conf:

TOOLBOX=dev

Restart Claude. Every MCP server and every Claude Code command now runs inside dev, with your files, your $PATH and your API keys – and your host stays clean.

3. Check it

In the Code tab, ask Claude to run:

which node uv git; test -f /run/.toolboxenv && echo IN-TOOLBOX

You should see paths from the toolbox and IN-TOOLBOX.

How the toolbox bridge works

  • At start the app asks your toolbox which commands it has and links each one into the sandbox – no hand-written list, new tools appear after a restart.
  • Commands enter the running toolbox directly (about 40 ms each); a stopped toolbox is started first.
  • Plugin output stays clean even if your ~/.bashrc prints a banner (fastfetch, motd…).
  • Use a different toolbox for one plugin with "command": "host-run", "args": ["--toolbox", "other", "server"].

Cowork on Silverblue

Cowork's cloud VM works immediately. For the local VM, your user needs KVM access:

sudo usermod -aG kvm $USER    # then log out and back in

Details in Cowork on Linux.

Why not rpm-ostree install?

Anthropic's package is a .deb, and layering packages onto an atomic system slows updates and can break rebases. A Flatpak is the native way to add apps on Silverblue and Kinoite, and this one updates itself like every other Flatpak.
