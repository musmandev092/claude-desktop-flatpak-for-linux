Every release of this Flatpak is found, built, tested, signed and published by GitHub Actions, in public, with no human step. Nobody builds a release on their own computer, and every run's log is public. This page shows what happens and how you can check it yourself.

What happens every hour, automatically

  1. Check – a job asks Anthropic's official apt repository (and Debian, for the VM firmware) whether there is a new version. It only reads.
  2. Build and test – the Flatpak is built from this public repository and installed exactly like a user would: Flatpak downloads Claude from downloads.claude.ai, checks its SHA-256, unpacks it and applies the Cowork patch. This job has no secrets.
  3. Security checks – the whole git history is scanned for leaked secrets (gitleaks), the workflows are audited (zizmor, actionlint) and every shell script is checked (ShellCheck).
  4. Publish – only if all of that passed, and only on the main branch: the update is committed by the github-actions bot, the repository is GPG-signed, the website and Flatpak repository are deployed, GitHub records a signed build provenance attestation, and a release is created with the full build record.

If a new Claude version breaks anything – for example the Cowork patch no longer fits – nothing is published and everyone keeps the last working version. The failed run stays visible.

What people did (once, at setup)

  • Wrote the packaging code, which is public in the repository with its full history.
  • Created the GPG signing key and stored it as an encrypted GitHub secret. Only the publish job can use it, and only after the tests passed.

Pinned tools are kept current by Dependabot pull requests, which are merged automatically only when every check passes on the exact commit.

Check a release yourself

1. It was built by this repository's workflow

curl -sO @URL@/BUILDINFO.json
gh attestation verify BUILDINFO.json -R musmandev092/claude-desktop-flatpak-for-linux

GitHub confirms which workflow run, commit and repository produced the file.

2. Your installed app is that build

flatpak info io.github.musmandev092.ClaudeDesktop | grep Commit
grep flatpak_commit BUILDINFO.json

Both show the same commit. Flatpak only installs it if the GPG signature matches key 633C 2A74 A8C7 B2A4 F67D AC05 F6E3 C4A7 C815 B241.

3. Claude itself came from Anthropic

grep -A2 claude_deb BUILDINFO.json

The URL is Anthropic's own repository, and the SHA-256 is checked by Flatpak on your computer before anything is installed.

4. Read every step

All runs, with their full logs, are public on the Actions page. Each release links the run that made it.

What stays your decision

  • COWORK=off runs the Claude app completely unmodified.
  • COWORK_LOCAL=on (off by default) runs the Cowork VM outside the Flatpak sandbox.
  • Plugins and Claude Code run your own commands on your host or in your toolbox – that is what they are for, so the sandbox is intentionally open for them.
