Anthropic ships the Claude desktop app for Linux only as a .deb for Ubuntu and Debian. This free, open-source Flatpak runs the same official app on Fedora, Fedora Silverblue, Arch, openSUSE and every other x86_64 distribution – with Claude Code, all local MCP plugins, Cowork and automatic updates.

Install Claude Desktop on Linux

flatpak install --user @URL@/claude-desktop.flatpakref

Then open Claude from your app menu (or run flatpak run io.github.musmandev092.ClaudeDesktop) and sign in with your claude.ai account. New Claude versions arrive through flatpak update, GNOME Software or KDE Discover.

Why this Flatpak

  • Built for atomic desktops. On Silverblue, Kinoite and Bazzite nothing is layered onto the OS; Claude's plugins use the tools in your toolbox.
  • Nothing redistributed. The Claude app is downloaded from downloads.claude.ai on your computer and checked against its SHA-256 checksum.
  • Safe updates. Each new Claude version is built and tested automatically; if Cowork's patch no longer fits, the update waits instead of breaking your app.
  • No human in the release process. Every release is found, built, tested, signed and published by GitHub Actions in public, with a build record you can verify – see how.
  • Heavily tested. Every release is install-tested and security-scanned in CI; the plugin bridge is additionally tested with 10,000 generated edge cases (odd arguments, 16 MB pipes, signals, broken settings, corrupted archives) and 20 security tests on a real desktop.

How it works

The Flatpak contains only packaging: a launcher, a bridge that lets the sandboxed app run your own commands (through the Flatpak portal, or inside a toolbox), and the QEMU, firmware and virtiofsd that Cowork needs. At install time Flatpak fetches Anthropic's official .deb (extra-data), verifies it and unpacks it. Read the source code and README for every detail.
