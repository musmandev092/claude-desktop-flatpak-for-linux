Claude Desktop has no official Arch Linux package. This Flatpak installs Anthropic's official Linux build on Arch Linux, Manjaro, EndeavourOS, CachyOS, Garuda and other Arch-based systems, keeps it sandboxed, and updates it automatically.

1. Install Flatpak (once)

sudo pacman -S --needed flatpak

Log out and back in once so the app appears in your menu. Manjaro, EndeavourOS and CachyOS often include Flatpak already.

2. Install Claude Desktop

flatpak install --user @URL@/claude-desktop.flatpakref

Answer yes if Flatpak offers to add Flathub (needed for the runtime). Open Claude from your launcher and sign in.

3. Plugins and Claude Code

Plugins run on your system with your own tools:

sudo pacman -S --needed nodejs npm uv git

Your MCP servers work unchanged – see the MCP servers guide. Prefer to keep them in a container? Install toolbox (sudo pacman -S toolbox), create one, and set TOOLBOX=name as in the atomic guide.

4. Cowork

Cowork works with Anthropic's cloud VM. For the local VM you need KVM and the vhost_vsock module:

sudo usermod -aG kvm $USER
sudo modprobe vhost_vsock

See Cowork on Linux.

Flatpak or AUR?

Community AUR packages exist too. The Flatpak runs the exact official build without repackaging it, isolates it from your system, and gets new Claude versions within about an hour through flatpak update.
