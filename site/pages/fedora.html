Claude Desktop has no official Fedora package – Anthropic only ships a .deb for Ubuntu and Debian. On Fedora Workstation and Fedora KDE the easiest way is this Flatpak: Fedora already includes Flatpak, you need no root, and no extra dnf repository.

1. Install

flatpak install --user @URL@/claude-desktop.flatpakref

Flatpak asks to add the Flathub repository for the runtime if you don't have it yet – answer yes. It then downloads the official Claude app from Anthropic, checks it and sets it up.

2. Open Claude and sign in

Open Claude from Activities (GNOME) or the application launcher (KDE), and sign in with your claude.ai account. The sign-in link from your browser opens the app automatically.

3. Claude Code and MCP plugins

On Fedora Workstation plugins run directly on your system, so install the tools they need as usual:

sudo dnf install nodejs uv git

Then add servers to Claude's config exactly as the official docs describe – "command": "npx" just works. See the MCP servers guide for examples.

4. Cowork (optional)

Cowork works out of the box with Anthropic's cloud VM. To run its VM on your own PC, see Cowork on Linux.

Updates and removal

flatpak update                                        # new Claude versions
flatpak uninstall --user io.github.musmandev092.ClaudeDesktop   # remove

Your chats live in your claude.ai account; local settings are in ~/.var/app/io.github.musmandev092.ClaudeDesktop/.

Flatpak or RPM?

Community RPMs also exist for Fedora. The Flatpak keeps the app separate from your system, gets new Claude versions within about an hour, and works the same on Fedora Atomic desktops – if you use Silverblue or Kinoite, it is the option that needs no layering.
