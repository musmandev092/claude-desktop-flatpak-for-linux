Claude Desktop for Linux

Unofficial Flatpak · Fedora, Silverblue, Arch, openSUSE & any distro · version @VERSION@

Anthropic ships the Claude desktop app for Linux only as a .deb for Ubuntu and Debian. This Flatpak runs the same official app on every other distribution, with Claude Code, all MCP plugins, Cowork and automatic updates.

Install Claude Desktop on Fedora, Silverblue, Arch or any Linux

flatpak install --user @URL@/claude-desktop.flatpakref

Then open Desktop client for Claude from your app menu. Updates arrive with flatpak update or GNOME Software, like any other Flatpak.

What works

  • Chat, projects and sign-in with your claude.ai account
  • Claude Code sessions and the built-in terminal, using your real tools
  • Every local MCP plugin (npx, uvx, docker, …) — no config changes
  • Cowork, with its virtual machine (needs KVM)
  • Works on atomic desktops: plugins can run inside your toolbox

Use your toolbox for plugins (Silverblue, Kinoite, Bazzite)

Create ~/.config/claude-desktop-flatpak/settings.conf with:

TOOLBOX=dev

Restart the app. Plugins and Claude Code now use the tools installed in that toolbox.

How it works — and why it's safe

This project publishes only packaging files (MIT licence). When you install, Flatpak downloads the official Claude package directly from downloads.claude.ai and checks its SHA-256 checksum. No Anthropic software is hosted or redistributed here.
