# Claude Desktop for Linux — Flatpak (unofficial)

Run the official **Claude Desktop** app on **any Linux distribution** — Fedora,
Fedora Silverblue / Kinoite / Bazzite, Arch, openSUSE and more — packaged as a
**Flatpak** with automatic updates.

> **Status:** 🚧 work in progress — not ready for use yet.

## What makes this different
- ✅ Chat, Claude Code, **all MCP plugins**, and **Cowork**
- ✅ Automatic updates, straight from Anthropic's official release
- ✅ Works on atomic/immutable systems (uses your toolbox for plugins)

## How it works (and why it's legal)
This repository contains **only packaging files** (MIT-licensed).
It does **not** contain or redistribute any Anthropic software.
When you install, Flatpak downloads the **official** `.deb` directly from
`downloads.claude.ai` and verifies its SHA-256 checksum.
